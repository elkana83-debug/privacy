Privacy Policy - Danidin YouTube Tools

Last updated: November 26, 2026

Danidin YouTube Tools is a private, internal application used only by its owner to upload, schedule and manage videos on the owner's own YouTube channels and to read those channels' own analytics. It is not offered to the public.

Data we access

With the channel owner's authorization through Google OAuth, the application uses the YouTube Data API and YouTube Analytics API to upload videos, edit video details and schedules, and read channel and video statistics for the owner's own channels.

How data is used and stored

Data is used only to manage the owner's channels. Access tokens are stored securely on the owner's private server and are never sold, shared with or transferred to third parties, and are not used for advertising.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
